O'zgarishlar (A)
  1. Asosiy natija — «~6,5M tejaldi» — pastdan yuqori o'ng burchakka, katta raqam bo'lib chiqdi.
  2. Rahbar jadvaldan ajratildi: bitta chiziqda «98% rahbar o'zi / 2% yordamchilarga». Ulush chizig'i faqat shu yerda ma'noli.
  3. Ustun sarlavhalari qo'shildi: Chaqiruv, Sarf, Tejadi — «2 ta» endi tushunarli.
  4. Model darajasi nishoni: nom + narx (×1/×3/×5) + 1–3 ustuncha. Rang yordamchi belgi, ma'no rangsiz ham o'qiladi.
  5. Chiziq endi foydani ko'rsatadi: 1 token sarfga necha token tejaldi. Qatorlar shu bo'yicha saralangan; ×1 dan pasti sariq.
  6. Ogohlantirish arzonroq yo'lni aytadi va «Sessiyalarni ko'rish» tugmasi bor; hisob formulasi «Qanday hisoblanadi?» ostida.
